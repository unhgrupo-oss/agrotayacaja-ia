# MotionSense AI

Aplicación Flask de reconocimiento de actividades humanas usando acelerómetro y giroscopio del smartphone.

- KNN
- Árbol de Decisión
- 6 actividades
- captura de 6 segundos
- ventanas de 2.56 s con 50 % de solapamiento
- interfaz móvil HTTPS

El modelo se genera automáticamente durante el build de Render usando señales crudas del dataset UCI Smartphone-Based Recognition of Human Activities and Postural Transitions (ID 341), mediante un espejo público de los archivos.
